# indra-index — единая витрина

Одна страница со всеми сервисами. Это то, что продвигается: один адрес,
один пост, одна ссылка.

**Адрес:** https://indra.rta.lat

## Почему одна страница, а не шесть

Шесть сервисов на шести адресах — значит шесть ссылок, каждую надо
продвигать отдельно. Ни одна из них не собирает аудиторию: это папка
с кодом, а не витрина.

## Запуск

```
python3 server.py --host 127.0.0.1 --port 8189
```

Чистый стандартный Python, без зависимостей. systemd-юнит
`indra-index.service`.

## Разметка

На странице стоят `<title>` и `description` под поисковый запрос,
`keywords`, OG-теги, `canonical` и `schema.org` со списком из шести
приложений — последнее читают агентные поисковики.

## Содержимое витрины

Внизу страницы — блок о том, чем эти сервисы **не являются**:
одноразовая церемония `ṚTA`, неаудированные схемы `attest`, демо-источник
тарифа, техническая проверка площадки вместо проверки добросовестности.
Без этого витрина продавала бы несуществующие гарантии.
